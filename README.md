# Network Engineering (PL)

Repozytorium dokumentujące moją naukę sieci komputerowych i rozwój w kierunku **Network Engineering**.

Znajdują się tutaj konfiguracje urządzeń sieciowych przygotowane w Cisco Packet Tracer, skrypty w Pythonie oraz materiały praktyczne utrwalające zdobytą wiedzę. Repozytorium służy zarówno jako notatnik techniczny, jak i prezentacja moich umiejętności oraz postępów w nauce.

## Zakres nauki

* **Networking Fundamentals** - podstawy sieci komputerowych, modele OSI i TCP/IP, adresacja IPv4 i subnetting.
* **Cisco Networking** - konfiguracja przełączników i routerów, VLAN-y, trunking, port security oraz routing.
* **Network Analysis** - analiza ruchu sieciowego przy użyciu Wiresharka i nauka interpretacji pakietów.
* **Python for Networking** - skrypty automatyzujące proste zadania sieciowe i wspierające naukę.

## Cel

Moim celem jest systematyczne rozwijanie praktycznych umiejętności sieciowych i przygotowanie do certyfikacji CCNA, a docelowo praca w obszarze Network Engineering.

Pozostałe projekty i szersze portfolio będą dostępne na mojej stronie internetowej - wkrótce.


# Network Engineering (ENG)

A repository documenting my journey into computer networking and my development towards a career in **Network Engineering**.

It contains network device configurations created in Cisco Packet Tracer, Python scripts, and practical exercises that help reinforce my knowledge. The repository serves both as a technical learning log and as a showcase of my skills and progress.

## Learning Focus

* **Networking Fundamentals** - networking concepts, OSI and TCP/IP models, IPv4 addressing, and subnetting.
* **Cisco Networking** - switch and router configuration, VLANs, trunking, port security, and routing.
* **Network Analysis** - analyzing network traffic with Wireshark and learning to interpret packets.
* **Python for Networking** - scripts for automating basic networking tasks and supporting practical learning.

## Goals

My goal is to build practical networking skills, prepare for the CCNA certification, and eventually pursue a career in Network Engineering.

More projects and an expanded portfolio will be available on my personal website soon.
